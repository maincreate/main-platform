# Security policy

TinkerTunnel is **pre-release**. Do not expose this initial MCP server to the public internet or attach privileged hardware automation.

There is currently no remote authentication, sandboxed job execution, or authorization for dangerous operations. The initial tools are strictly read-only.

Please report vulnerabilities privately to maintainers via GitHub private vulnerability reporting once enabled. Never put secrets, tokens, personal data, or signing keys in issues.
