03 · SECURE TUNNEL

External connectivity, isolated gateway

Cloudflare Tunnel runs as an optional container. Create a remotely managed Cloudflare Tunnel, then add its connector token as TT_TUNNEL_TOKEN to Coolify's protected environment variables.

1. Create a tunnel in Cloudflare Zero Trust → Networks → Tunnels.

2. Configure only the MCP hostname to proxy to http://gateway:3001 on the TinkerTunnel Docker network.

3. Enable the Compose tunnel profile when authentication is ready. Do not publish the controller portal.

4. Verify the connector and TLS/hostname through Cloudflare; a saved hostname does not prove the tunnel is online.

Remote ChatGPT connections still require supported OAuth authorization. Do not consider a running cloudflared container proof that ChatGPT integration is ready.

04 · MCP SERVER

Read-only tools, separate gateway

Configure TT_MCP_TOKEN and TT_SERVICE_TOKEN (each at least 32 random characters) in Coolify. The default MCP endpoint is locally bound to http://127.0.0.1:13001/mcp.

Available: tinkertunnel_status, tinkertunnel_list_runners, tinkertunnel_framework_catalog, tinkertunnel_plan_install.

Not available: installs, builds, flashing, publishing, arbitrary shell, and remote ChatGPT OAuth. All execution must remain policy-gated.
