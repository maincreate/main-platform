Set up the GitHub connection

To connect, TinkerTunnel needs a dedicated GitHub App with Device Flow enabled. You can configure its public Client ID here once; no access token, password or private key is needed.

Don't have a GitHub App? Register one on GitHub under your chosen owner or organization. Enable Device Flow in the App's settings. For the first release, use read-only repository metadata permissions; avoid requesting additional access until it's needed.

A deployment integration's GitHub App is a different concern and should remain separate.

Authorize your GitHub account

You'll approve TinkerTunnel on GitHub. No personal access token or private key needs to be pasted here.
