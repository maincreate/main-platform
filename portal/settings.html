Advanced notes and other assistants

The local MCP server only listens inside the Main{Create} container. Its access token is generated automatically, and MCP actions retain Main{Create}'s approval rules. The OpenAI tunnel client only makes outbound HTTPS connections.

Claude is deferred; no public MCP endpoint has been enabled. Self-managed Docker/Compose configuration is available for advanced deployments but is not needed for the normal connection flow.
