Add a build machine

Install the lightweight Host Service on the machine to connect outbound to this controller.

Controller:

Install Node.js 22+ and obtain the TinkerTunnel repository on your machine.

From a terminal in the repository directory, run:

node runner/service.mjs pair

The Host Service asks for controller URL, local TinkerTunnel username and password, then exchanges them for per-host credentials. It doesn't store your password.

Start the host connection:

node runner/service.mjs run

The service connects outbound without requiring SSH or an inbound port.

Pairing supports Linux, Windows and macOS with Node.js 22+. Native installers and automatic GitHub Actions runner registration are not yet available through this service.
