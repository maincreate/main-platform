Add a build machine

Linux ARM64 / Raspberry Pi OS Lite (64-bit) — first-run alpha. Configure hostname, user, password, and SSH in Raspberry Pi Imager. The installer prepares the host; the controller handles GitHub registration after pairing.

1. Install once on the Pi

SSH into the freshly imaged Pi, then run this command. It installs the Host Service, enables it at boot, and advertises the host on mDNS.

This release requires Linux ARM64 (aarch64). The controller address is . Other OS installers are planned; do not use this command on x64, macOS, or Windows.

2. Connect your host

Confirm this is your Pi before sending credentials. Compare the SSH fingerprint with the value on the Pi:

ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub

After pairing, the controller automatically requests a scoped GitHub Actions registration token and configures the runner under the Pi's actual hostname. If GitHub access is not ready, the Pi stays paired and shows a clear retry action. No GitHub credentials are entered on the Pi.
