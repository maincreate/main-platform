    Select operating system and architecture

    Available for testing · Raspberry Pi OS Lite 64-bit. In Raspberry Pi Imager, set a hostname, local username/password, and enable SSH with password authentication. Boot and SSH into the Pi.

    One-time installer: Linux ARM64 only. A successful install verifies the Host Service—not the GitHub runner. Pair the host, complete runner setup, and confirm Online status.

    Coming soon. A native Linux x64 installer and controller-managed runner provisioning are planned for VMs and x86 mini PCs. The ARM64 installer will not work here.

    Coming soon. Intel Mac hosting, launchd and Xcode toolchain discovery are planned. No native installer is released for this platform.
