Add a build machine

Connect a Linux, macOS, or Windows machine using the outbound TinkerTunnel Host Service. No inbound SSH, passwords sent to the controller, or open ports on the host.

Controller:

1. Prepare the build machine

Install Node.js 22+ and Git, then run the following on the build machine itself:

git clone https://github.com/TinkerTunnel/tinkertunnel.git
cd tinkertunnel
node runner/service.mjs pair

2. Pair locally

The Host Service asks for this controller URL and your TinkerTunnel administrator username and password in the machine's terminal. It obtains a one-time enrollment credential and saves only the new machine credential.

3. Start outbound connection

node runner/service.mjs run

Current MVP: the Host Service runs in the terminal, not yet as a permanently installed OS service. GitHub Actions runner installation is separate and not automated yet. The controller must be reachable over trusted HTTPS from the build machine.
